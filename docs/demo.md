# Demo Script

1. Open the dashboard (frontend on :3000).
2. Idea pre-filled: "I want to build an AI platform that helps engineering students find relevant internships."
3. Click **Validate My Idea**.
4. Watch live agent activity: Research, Synthetic Market, Customer Discovery running in parallel; Voice waits for consent.
5. Synthetic market: 10,000 participants, segment table, best scenario (SIMULATED badge).
6. Research stream shows evidence counts (REAL/DEMO badges).
7. Click "Grant consent & interview" on a test candidate → simulated voice interview runs, interview result appears, hypotheses update.
8. Market Fit card: score + confidence + dimensions + evidence stream cards.
9. Evidence conflicts panel shows disagreements (e.g., pricing uncertainty).
10. Scenario testing: click "Test ₹49/₹99/₹199".
11. Opportunities: hackathon found (DEMO label), CalendarAgent logged preparation events.
12. Generated assets: deck, website content, MVP plan.
13. Close with: "The founder never manually coordinated any of these tasks."

Everything shown maps to real backend events stored in the event log. Labels distinguish REAL vs SIMULATED vs DEMO at all times.
